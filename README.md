API backend desenvolvida em **TypeScript** focada em planejamento financeiro, inteligência de gastos e gestão de patrimônio pessoal.

---

## 📌 Sobre o Projeto

O **FinanCida** é uma solução completa para transformar a forma como pessoas e famílias gerenciam suas finanças. A API foi arquitetada com foco estrito em **Clean Code**, funções enxutas, separação de responsabilidades e tipagem estrita de dados.

## 🚀 Funcionalidades

- 📊 **Gestão de Fluxo de Caixa:** Lançamentos de receitas, despesas fixas e variáveis.
- 🎯 **Metas e Orçamentos:** Definição de limites orçamentários por categoria e acompanhamento de progresso.
- 📈 **Projeção Patrimonial:** Cálculos de estimativa de crescimento com juros compostos.
- 🔐 **Autenticação e Segurança:** Proteção de endpoints e isolamento de dados por usuário.

## 🛠️ Tecnologias Utilizadas

- **TypeScript** & **Node.js**
- Arquitetura baseada em Clean Code e Domain-Driven Design (DDD)
- Validação e serialização estrita de schemas

## ⚙️ Como Executar Localmente

### Pré-requisitos
- Node.js 18+ instalado
- npm ou pnpm

```bash
# 1. Clone o repositório
git clone https://github.com/IuryAlmeidaDev/financida-api.git
cd financida-api

# 2. Instale as dependências
npm install

# 3. Inicie o servidor em modo de desenvolvimento
npm run dev
```
